# Parents-Teacher Communication Portal

A Python-based portal designed to improve communication between parents and teachers.

## Features

- Parent Login
- Teacher Login
- Student Performance
- Attendance and Marks
- Homework / Assignments
- Parent-Teacher Messaging
- Leave Request
- Leave Approval / Rejection
- Teacher Announcements

## Technologies Used

- Python
- SQLite
- Google Colab

## Project Type

First Year Academic Project
